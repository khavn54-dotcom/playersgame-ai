# PLAYERSGAME AI V1

## Chạy
npm install
npm run dev
Mở http://localhost:3000

## Deploy miễn phí
Đưa project lên GitHub rồi import vào Vercel. Không cần mua domain; Vercel cấp URL miễn phí dạng *.vercel.app.

## Lưu ý
V1 lưu API key trong localStorage để thử nghiệm. Bản production nhiều người dùng nên bổ sung đăng nhập, mã hóa secret và database. Video route là generic adapter; Seedance/Omni cần chỉnh endpoint/schema theo gateway API cụ thể.
